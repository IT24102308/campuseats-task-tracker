# CampusEats Task Tracker

A lightweight task management tracker for the CampusEats engineering team.

## Overview
This repository manages task tracking, collaboration workflows, continuous integration, and secure code practices for CampusEats developers.

## Features
- Task tracking and order workflow management
- GitHub Flow branching and pull request review process
- Automated CI pipeline using GitHub Actions
- Secure coding and environment configuration standards

## Getting Started
```bash
node src/tasks.js
```
